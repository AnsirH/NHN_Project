# 장군 스킬 사양서 (인게임 구현 기준)

> 작성: 2026-07-24 / 대상: 아웃게임 연동 공유용
> 아웃게임의 `generalSkillId`가 가리키는 대상이 이 문서의 장군들입니다.
> **병과가 장군 스킬을 결정**하므로, 병과 1종 = 장군 1종 = 스킬 1종으로 1:1 대응합니다.

---

## 0. 공통 규칙 (모든 장군에 동일 적용)

**구성**: 장군 1명 = **패시브 1개 + 액티브 1개**. 분대마다 장군 1명이며, 같은 장군이 여러 분대에 동시에 쓰일 수 있습니다(분대별로 게이지가 따로 찹니다).

**패시브** — 장군이 **살아 있는 동안만** 부대 전체에 적용되는 지속 버프. 현재 4종 모두 `부대 공격력 +15%`입니다.

**액티브 (충전식)** — 마나나 쿨다운이 아니라 **전투 이벤트가 게이지를 채웁니다.**
```
전투 이벤트 발생 → 게이지 +1 → 임계치 도달 시 자동 발동 → 게이지 0으로 리셋 → 다시 충전
```
- 플레이어가 시전하지 않습니다. 조건이 차면 알아서 터집니다.
- 재충전되므로 한 전투에서 여러 번 발동합니다 (목표: 전투당 2~3회).
- **장군이 죽으면**: 패시브 즉시 소멸 + 게이지 소멸 + 이후 충전·발동 없음. 부대의 롤(병과)은 유지됩니다.
  → 별도의 디버프 없이 "장군을 잃은 부대는 약해진다"가 자연스럽게 성립합니다.

**스킬 강화 (`generalSkillUpgradeCount`)** — 아웃게임에서 장군 스킬 강화 증강을 고른 횟수만큼
**충전이 더 빨리 찹니다 = 스킬이 더 자주 터집니다.** 효과 수치가 세지는 게 아니라 **발동 빈도가 늘어납니다.**

| 강화 횟수 | 충전 필요량 |
|---|---|
| 0회 | 100% (기본) |
| 1회 | 85% |
| 2회 | 70% |
| 3회 | 55% |
| 4회 이상 | 40% (하한) |

하한을 둔 이유는 강화가 쌓여도 스킬이 매 순간 터지는 소음이 되지 않게 하기 위함입니다.
위 수치는 밸런싱 데이터라 튜닝으로 바뀔 수 있습니다 — **UI에 수치를 하드코딩하지 말아 주세요.**
설명 문구는 "강화할수록 스킬이 더 자주 발동" 수준이면 안전합니다.

**연출 명세 (뷰 구현 예정)**: 발동 순간 짧은 슬로모 + 장군 발광 + 부대 전원 동일 모션.
현재는 시뮬레이션만 구현돼 있고, 발동 시각은 뷰가 읽을 수 있게 노출돼 있습니다.

**배치**: 장군은 분대 선두(병사 최전열보다 한 줄 앞)에 섭니다. 앞뒤 정도는 데이터로 조정 가능합니다(−1~+1 랭크).

## 1. 전사 장군 — 「방진」

| 항목 | 값 |
|---|---|
| 패시브 | 부대 공격력 **+15%** |
| 액티브 효과 | 부대 전원이 **받는 피해 70% 감소** (피해 배율 0.3), **2.5초** 지속 |
| 충전 조건 | **부대원 누적 사망 4명** |
| 컨셉 | 아군이 쓰러지기 시작하면 대열을 맞물려 버틴다 |

전선이 무너지려는 순간 자동으로 터지는 구조라, 방패 아이템의 정체성과도 맞습니다.
아웃게임의 방패 아이템 병과(`ArmyClass.Shieldman`)가 이 전사 장군에 매핑됩니다.

---

## 2. 궁수 장군 — 「일제 사격」

| 항목 | 값 |
|---|---|
| 패시브 | 부대 공격력 **+15%** |
| 액티브 효과 | 부대 **전원이 동시에 발사** → 적이 가장 밀집한 지점 주변(반경 2.5)에 화살비. 화살 1발당 피해 = 각자 공격력 ×1.0 |
| 충전 조건 | **부대 누적 공격 40회** |
| 컨셉 | 평소엔 각자 쏘다가, 한 번씩 지휘에 맞춰 일제히 퍼붓는다 |

적 밀집 지점을 자동으로 탐색해 그쪽으로 쏩니다. 뭉쳐 있는 적에게 특히 강합니다.

---

## 3. 암살자 장군 — 「그림자 습격」

| 항목 | 값 |
|---|---|
| 패시브 | 부대 공격력 **+15%** |
| 액티브 효과 | 부대 전원이 **다시 은신(2초)** + 은신 해제 후 **첫 공격 2배 피해** |
| 충전 조건 | **부대 누적 처치 4명** |
| 컨셉 | 한 번 죽이기 시작하면 그림자로 사라졌다가 다시 덮친다 |

은신 중에는 적의 타겟이 되지 않고 전열을 통과해 이동합니다(단 광역 피해에는 맞습니다).
※ 1차 아이템에 암살자가 없어 현재는 적 구성 전용입니다.

---

## 4. 사냥꾼 장군 — 「사냥 선포」

| 항목 | 값 |
|---|---|
| 패시브 | 부대 공격력 **+15%** |
| 액티브 효과 | 현재 **체력이 가장 높은 적 1명에게 표식** — 그 대상이 받는 피해 **×1.5**, **6초** 지속 |
| 충전 조건 | **8초 경과** (시간형) |
| 컨셉 | 가장 위협적인 놈을 지목하면 부대가 그쪽으로 달려든다 |

사냥꾼 롤은 **표식·중독 대상을 우선 공격**하는 타겟팅을 갖고 있어서, 선포 → 집중 사격이 자동으로 이어집니다.
※ 1차 아이템에 사냥꾼이 없어 현재는 적 구성 전용입니다.

---

## 5. 노멀 장군 (아이템 미부여)

| 항목 | 값 |
|---|---|
| 패시브 | 없음 |
| 액티브 | 없음 |
| 컨셉 | 능력은 없지만 병사보다 튼튼한 지휘관 |

체력·공격력만 병사보다 높고 크기도 커서 전장에서 즉시 구분됩니다.
`ArmyClass.None`(아이템 미부여) 부대가 이 장군을 갖습니다.

## 7. 아웃게임 쪽에서 알아두면 좋은 점

- **`generalSkillId`는 병과에서 파생됩니다.** 병과가 정해지면 스킬도 자동으로 정해지므로, 별도 선택 UI는 필요 없습니다.
  키 값은 인게임 장군 데이터 이름을 그대로 쓰는 것을 제안합니다 (`ArcherGeneral` 등). 다른 규약이 편하시면 맞추겠습니다.
- **위 수치는 전부 밸런싱 튜닝 대상입니다.** 충전 필요량·지속시간·배율 모두 데이터라 코드 수정 없이 바뀝니다.
  장군 정보 팝업에 스킬 설명을 노출하실 계획이면, **수치를 UI에 하드코딩하지 말고** 텍스트만 두시거나
  필요한 값을 알려주시면 전달 경로를 만들겠습니다.
- **패시브는 눈에 보이지 않아도 됩니다** (기획상 "비가시 허용" 계층). 액티브만 연출로 확실히 보이면 됩니다.
- 장군 사망 = 부대 약화가 설계 의도입니다. 아웃게임에서 "장군을 잃으면 손해"라는 표현이 필요하면
  **전투 중 사망은 런 자산에 영향을 주지 않는다**(부대는 영구 자산)는 현재 규칙과 충돌하지 않는지만 확인 부탁드립니다.
