아웃 게임 기획 내용이다.

이 게임은 Mini Warriors를 모티브로 삼은 다 대 다 전투 게임이다.

거기에 로그라이크(랜덤맵+레벨업 증강) 요소를 추가한다.

작업 분담을 했기 때문에 아웃 게임 구현만 진행한다.

# 필수 구현 사항
메인 메뉴, 맵 선택(일단 맵은 하나만 구현), 방 선택(로그라이크 방식의 그래프 방), 방 이벤트 연출, 군대 배치 UI


Mini Warriors 게임을 조사해보면 군대를 편성할 수 있다는 것을 알게 된다.

우리는 이 방식과 마인크래프트의 점토병사 모드의 매커니즘을 합칠 것이다.

즉, 군대는 원래 능력이 없는 기본 군대이며, 아이템을 주었을 때 능력을 얻는다.

기본 군대 + 활 => 궁수 군대
기본 군대 + 안장 => 기마 군대

군대와 아이템은 방을 진행하면서 얻을 수 있고 그걸 배치하고 아이템을 부여하면서 전술을 짜 나가야 한다.

아이템은 한 번 주면 귀속되는 형태이다. 따라서 귀속된다는 경고 팝업을 띄워야 하고 '다시 표시하지 않음' 체크 박스를 넣어서 자연스럽게 게임 매커니즘을 익히도록 한다.

씬은 다음과 같이 나눈다.

1. 메인 메뉴
2. 맵 선택 씬
3. 인게임씬

아웃게임을 만들기로 했지만 인게임씬을 만드는 이유는 다음과 같다.
1. 맵은 방으로 구성되어 있다.
2. 방을 선택하는 UI는 인게임씬에서 띄울 것이다.
3. 방을 선택하고 나면 군대 배치 UI를 띄울 것이다. 군대 배치 UI에서는 군대 배치와 아이템 부여를 할 수 있다.
4. 방과 군대 배치를 마치면 그 데이터로 바로 인게임 진행을 할 것이기 때문에 인게임씬을 구현한다.
5. 우리가 만든 위 UI를 인게임 구현 개발자가 바로 사용할 수 있는 구조로 만들어야 한다.(프리펩 혹은 사용이 쉽게 되어 있는 컴포넌트 등 고민 필요)
